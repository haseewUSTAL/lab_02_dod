## Сборка и запуск проекта

### Ручная сборка:
1. Создать каталог для скомпилированных классов:
   `javac -d out $(find . -name "*.java")` (Linux/macOS)
2. Собрать JAR-файл с указанием манифеста:
   `jar cvfm Lab2.jar manifest.txt -C out .`
3. Запустить приложение:
   `java -jar Lab2.jar`

### Автоматическая сборка:
* **Linux/macOS:** запустить `./build.sh`
* **Windows:** запустить `build.bat`
